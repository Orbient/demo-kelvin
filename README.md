# Кельвин — демо-сайт студии света

**Смотреть:** https://orbient.github.io/demo-kelvin/ · English: https://orbient.github.io/demo-kelvin/?lang=en

Демонстрационный сайт вымышленной студии освещения, сделанный студией [Orbient](https://orbient.pro). Светильники, цены и адреса — образец; фото и видео взяты со стоков, авторы перечислены на странице [credits](https://orbient.github.io/demo-kelvin/credits.html).

Что внутри:
- первый экран, где лампа включается от прокрутки, и название, нарисованное нитью накала;
- «Тёмная комната»: свет по источникам, яркость и оттенок от свечи до холодного белого;
- витрина в темноте, карточки товаров с примеркой светильника на своём фото;
- дача, где окна загораются по одному, карта объектов, раздел для дизайнеров;
- заявка с живой сметой; русская и английская версии; диммер оттенка на весь сайт.

Чтобы показать демо конкретной компании, добавьте к ссылке её название: `?brand=Название`.

Стек: React, Vite, GSAP, Lenis, WebGL. Сборка и выкладка: `npm run deploy`.
